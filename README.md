CLoud Document Approval System

The Cloud Document Approval System is a web-based application designed to simplify the submission, review, approval, and tracking of documents. It aims to make document processing more organized, transparent, and accessible to authorized users.

Objectives
-Digitize the document submission and approval process.
-Allow users to monitor the status of submitted documents.
-Organize document reviews and approvals in one platform.
-Reduce manual paperwork and improve document management efficiency

Core Features
-Document Submission – Submit documents for review and approval.
-Approval Workflow – Route documents to the appropriate reviewers or approvers.
-Document Tracking – Monitor document status and progress.
-User Interface – Provide an organized interface for navigating the system.

Techstack:
-React
-TypeScript
-Vite
-HTML and CSS
